## Behaviour and deliberate boundaries

- PDF full-page embedded images, native PDF tables with repeated aligned text
  columns, PPTX embedded images and simple native tables are retained locally.
  Existing format, ZIP/XML, metadata, privacy and scientific-date gates remain
  mandatory. Mixed/raster-overlaid PDF pages, vector/grid PDF tables, merged
  PPTX cells, opaque embedded objects and unsupported formats remain refused.
- Native PDF table detection is conservative: at least two rows/columns,
  inter-column gaps of 40 points, column alignment within 2 points, row gaps
  at most 40 points. It produces **candidate tables**, not validated scientific
  interpretations. Complex/multiline or less widely spaced tables are not
  qualified by this implementation. Text-only PDF behaviour remains available
  for ordinary paragraphs. Table-bearing pages additionally undergo native
  rendered-pixel and text screening before acceptance.
- Image bytes and canonical JSON table cells reside in the existing private
  SQLite source records. No new disk cache, staging image, search index or
  temporary source file is created. Existing source deletion, secure database
  cleanup and Project invalidation cover these records and their copies.
  Derivatives are bounded to 200 items, a 10 MiB aggregate base64 budget and
  a 60-second extraction budget, in addition to original-reader limits.
- Each identity includes original SHA-256, original locator, kind, coordinates
  and derivative SHA-256. Identical shapes have separate occurrence identities;
  an identical original reimport has reproducible derivative identities.
  Verification re-extracts from the original; a matching caller-provided hash
  alone is never sufficient. Locations follow PDF page / PPTX presentation
  order, not archive entry order. Coordinates are finite normalized rectangles.
- The scientific date belongs to the source. No derivative publication date is
  invented. Embedded image metadata and explicit PPTX shape descriptions/titles
  can supply attributed fields. Automatically generated `image.png`/JPEG names
  are not captions. Nearby labelled text is retained as ambiguous or not
  attributable, never silently assigned to a particular item. Whole-document
  authorship is not automatically figure authorship.
- Missing, present, ambiguous, contradictory and not-attributable field states
  remain visible. Corrections are restricted to selecting an actually recorded,
  attributable candidate or withdrawing an attribution. Free-form invented
  captions, authors, rights, organisations and provenance are rejected.
  Review history retains the initial and corrected values, authenticated actor,
  UTC timestamp, revision and both original/derivative hashes. Candidate values
  and their origins remain immutable after review.
- A source with pending assets cannot reach presentation selection, context
  construction or model entry gates. OCR still requires its separate review.
  The actual derivative bytes are never added to evidence prompts; retained
  items remain `evidence_eligible=false`, even after local review. Confirmation
  permits the source's separately verified text to proceed through existing
  evidence gates, not direct image citation/generation or automatic visual reuse.
- Reviews use `BEGIN IMMEDIATE`, optimistic review revisions and the existing
  Project revision mechanism. Source updates, dependent invalidation and Project
  audit events share the transaction. The private source's append-only review
  history remains available when it is detached from all Projects. Errors and
  general Project audit events do not duplicate correction text or image bytes.
- An explicit preparation operation enriches original 05.1 inventories and
  older PDF sources without replacing the original, changing its hash, or
  granting confirmation. Every old PPTX descriptor and the remaining source
  fields must match a freshly screened original. Failed audit rolls back this
  enrichment. Reopening the review triggers preparation; normal startup does
  not depend on running native OCR to retain or delete existing data.
- PDF review shows a freshly rendered original region beside the derivative.
  PPTX review shows original embedded image bytes / native table cells and exact
  shape location; **it is not a faithful full-slide renderer**, including crop,
  theme and typography effects. The verified original can be downloaded for
  comparison in a local viewer. This limitation remains for manual review.
  Original/preview endpoints are owner-authorized, `no-store`, and do not make
  durable previews. Browser blob URLs are revoked on close, source removal,
  Project change or logout.

## Verification record

Development used failing behaviour tests before implementation: initial
retention (3 failures), authenticated review (missing operation), API review
(404), legacy preparation (missing operation), and invalid query error leakage.
These were implementation checkpoints, not successful checks. An intermediate
full run had 12 failures: an overly broad PDF table detector and expected gate
changes. The detector was replaced rather than weakening privacy or OCR gates.
A later embedded-caption test exposed autogenerated image filenames being
mistaken for captions; these are now excluded.

Commands and final results are recorded in the phase handoff. Full suite includes
`app/tests` explicitly. Two existing browser tests remain skipped on macOS 10.15;
no browser execution, screenshots or human approval is claimed. The new browser
asset-review flow still needs execution on a supported browser environment.

`venv/bin/python -m app.tests.evaluate_assets_native` exercised real native OCR
without doubles: a text-image PPTX was accepted; a possible name and a schematic
face were refused; PDF image/table hashes and original-region previews were
verified. Native commands initially failed inside the containing Codex sandbox,
then ran successfully with approved execution while retaining the native helper's
own sandbox. These five synthetic probes are **not** evidence of general privacy
accuracy, anonymisation, visual fidelity or scientific validity.

# Slice 01.3 — MVP interface-scope evidence

Date: 2026-09-15. Authority: PRD NFR-01, NFR-03, NFR-04, NFR-06 and §18.
This is the final authorised implementation slice of phase 01. It is not a
phase-gate approval, complete PRD compliance, scientific validation, or a
supported-environment browser verification.

## Delivered behaviour

1. `/app` registration now sends the fixed `professor_medicine` persona. The
   role selectors are removed from registration and the signed-in workspace.
2. Registration, account preferences and new-presentation language selectors
   expose only English and French. `language()` falls back to English for a
   pre-existing unsupported preference, so an old Arabic profile still opens
   safely without being silently rewritten.
3. Existing profile data is retained when only its language preference is
   updated: the hidden role is sent unchanged to the existing authenticated
   API. The interface does not render it as an available choice.
4. The evidence settings panel keeps the required public/synthetic disclosure
   and declaration, but no longer renders BM25/direct retrieval selection.
   `PUT /projects/{user_id}/{project_id}/evidence-settings` remains available
   to existing/API clients and retains deterministic server enforcement.
5. No Streamlit feature was added or changed. Domain profile/language contracts
   stay broader than the MVP UI so existing persisted accounts can be resumed.

## Delivered behaviour

1. Removed `POST /auth/reset-password`, the `/app` reset button/action, and
   `UserSessionRepository.reset_password_without_verification`. A request to
   the historical endpoint now receives FastAPI's 404 and cannot alter an
   account or issue a token.
2. Retained the server-side owner checks and added direct HTTP regressions that
   prove a second authenticated synthetic user receives 403 before reading or
   mutating the owner's Projects, resources, templates, jobs, events or export.
   Equivalent requests without a bearer token receive 401.
3. Added `LOCAL_BIND_HOST`, defaulting to `127.0.0.1`, and rejects every
   non-loopback value, including `0.0.0.0`. The module entrypoint consumes this
   setting and the README startup command passes `--host 127.0.0.1` explicitly.
   This protects the supported local startup path; it cannot prevent a user who
   deliberately invokes an external Uvicorn command from overriding its host.

The changes retain local registration/login and persistent Project recovery.
No account-recovery replacement is implemented: a forgotten password requires
explicit future product design and authorisation. No new Streamlit feature was
added.
